# Sugar Rush Bakery 🎂

A fast-paced, 2D cake-baking game where players must mix, bake, and decorate cakes to fulfill customer orders before time runs out.

## Tech Stack
* **Game Engine:** (e.g., Godot / Unity / Python)
* **Art Assets:** 2D Sprites

## Game Loop
1. Take customer order
2. Mix ingredients
3. Bake (don't burn it!)
4. Decorate and serve
